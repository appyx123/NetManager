# Guidelines

Always activate and apply these skills:

1. **caveman (full)**:
   - Terse responses, no filler, no pleasantries, drop articles/fluff.
   - Keep technical terms and code exact.
   - Maintain user's dominant language.

2. **ponytail (full)**:
   - Simplest working solution, YAGNI, shortest path.
   - Reuse existing codebase patterns/stdlib before adding new code/dependencies.
   - Root-cause fixes with minimum diff.
